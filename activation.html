03Activation

One command activates Windows and Office.

Microsoft Activation Scripts (MAS) is a small open-source script that talks to Microsoft’s own activation services for you. You run one line in PowerShell, pick what you want from a menu, and the script does the rest — no files left behind, no permanent service running.

1 · Run the command

Press Win, type PowerShell, open it, and paste this line — then press Enter.

irm https://get.activated.win | iex

irm downloads the script, iex runs it in memory. Nothing is saved to disk, and an elevated prompt is not required for most options.

2 · Pick from the menu

The script shows a numbered list. Type the number next to the method you want and press Enter.

PowerShell
Microsoft Activation Scripts
--------------------------------------------------------------
  [1] HWID          Windows 10 / 11                  Permanent
  [2] Ohook         Office                           Permanent
  [3] TSforge       Windows / Office                 Permanent
  [4] KMS38         Windows 10 / 11 / Server         Until 2038
  [5] Online KMS    Windows / Office                 180 days
  [6] Check activation status
--------------------------------------------------------------
  Choice:

Menu wording can change between releases. Look for HWID for Windows and Ohook for Office — the letters matter more than the number.

Windows — which method?

HWID

Locks the licence to the machine’s hardware ID. Survives reinstalls and updates; stays permanent as long as the motherboard does not change.

Best for: Windows 10 / 11 · permanent

TSforge

Patches the local activation store offline. Works across Windows 7–11 and Server without contacting Microsoft.

Best for: offline machines · permanent

KMS38

Extends the KMS grace period to 2038. No background service, no renewal, but it is not truly permanent.

Best for: Windows 10 / 11 / Server · until 2038

Online KMS

Reaches a KMS server and renews every 180 days through a scheduled task. The most compatible option for Server.

Best for: Server · renewable 180 days

Office — which method?

Ohook

Hooks the Office activation check on the machine instead of editing licence files. Permanent, and it never contacts a licence server.

Best for: Office 2013–2024 / 365 (click-to-run) · permanent

Online KMS

The same 180-day KMS route used for Windows, applied to Office. A scheduled task renews it in the background.

Best for: Office (C2R) · renewable 180 days

Office must be the click-to-run (C2R) build. MSI installs and the Mac version are not covered — see the source page for those.

3 · Confirm it worked

slmgr /xpr

Windows shows “permanently activated” (or the expiry date). For Office, open any app → Account → the licence line should read Product Activated; option 6 in the menu reports both.

Good to know

  • The script comes from massgrave.dev and is open source; the project’s source is on GitHub. Only run it from the official get.activated.win address — reposted copies are not trustworthy.
  • It is not affiliated with Microsoft. Activation outside a valid licence breaks the Microsoft terms of service; this page explains the tool, it does not condone misuse.
  • Nothing is installed permanently: the script downloads, runs in memory and cleans up. HWID and Ohook survive updates; KMS methods depend on the scheduled task.
  • Blocked by antivirus? That is a false positive on the downloader; check the source page’s troubleshooting section before disabling anything.
