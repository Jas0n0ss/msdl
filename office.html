04Office

A clean Office install before you activate it.

Office installs through click-to-run (C2R), not an MSI. There are two sane ways to get it: build it yourself with Microsoft’s Office Deployment Tool, or take a ready-made C2R image. This page walks both, then hands you to the activation guide.

1 · Know what you are installing

  • Microsoft 365 — subscription, always updated. Product id O365ProPlusRetail.
  • Office 2024 / 2021 / 2019 — one-time licence. Volume ids look like ProPlus2024Volume, retail ids like ProPlus2024Retail.
  • Architecture — pick x64 unless a 32-bit add-in forces x86. Never install both side by side.
  • Channel — Current for 365, PerpetualVL2024 for the 2024 volume line. The id and channel must match the licence you will use.

Microsoft publishes the full product-id list in its ODT documentation. If an id is wrong, setup simply refuses to start — nothing breaks.

2 · Route A — Office Deployment Tool (official)

Download the ODT from Microsoft (it is a small setup.exe plus samples), then drop a configuration.xml next to it.

<Configuration> <Add OfficeClientEdition="64" Channel="Current"> <Product ID="O365ProPlusRetail"> <Language ID="en-us" /> </Product> </Add> <RemoveMSI /> <Display Level="Full" AcceptEULA="TRUE" /> </Configuration>
setup.exe /download configuration.xml
setup.exe /configure configuration.xml

The first command fills a local Office folder with the installer (a few GB). The second installs from it, silently and without a browser.

3 · Route B — ready-made C2R image

If you do not want to write XML, the MASSGRAVE project publishes pre-built click-to-run images for every edition and language: pick the edition, copy the address, run it.

  • Office C2R links — one installer per edition and language, hosted by Microsoft.
  • Custom C2R builder — tick the apps you want, get a trimmed installer.
  • Office for Mac — the macOS route, which uses a different installer entirely.

These are catalogue pages, not downloads we host. The files themselves always come from Microsoft’s own CDN.

4 · Install, then check

PowerShell (admin)
# remove any older Office first (optional)
setup.exe /configure remove-old.xml

# install
setup.exe /configure configuration.xml

# confirm what landed
cscript "C:\Program Files\Microsoft Office\Office16\OSPP.VBS" /dstatus

A healthy install reports the edition, the channel and a licence status. If it says unlicensed, that is expected before activation — continue to the activation guide.

Good to know

  • Mixed installs are the usual cause of “something went wrong”: uninstall every old Office (MSI and C2R) before installing a new line.
  • The installer needs a stable connection and 5–10 GB free. Running it twice in parallel corrupts the installation.
  • Office 365 and the perpetual editions can coexist only as separate channels — do not mix retail and volume ids in one configuration.
  • After a successful install, Office updates itself. Activation is covered on the activation page.
